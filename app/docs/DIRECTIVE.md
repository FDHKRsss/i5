# Quality directive (the codebase must conform to these rules)

_Seeded defaults; the molter refines these from the project's real conventions._

- No dead or unreachable code; no unused symbols or imports.
- No duplication of logic; one job is done one way.
- Tests assert real behavior (no vacuous/always-true tests).
- Names and messages tell the truth (no lying labels).
- No leftover scaffolding, debug prints, or commented-out blocks.
